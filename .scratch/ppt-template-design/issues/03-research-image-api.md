# 调研动态搜图图库 API 选型

Type: research
Status: resolved

## Question

对比可用于动态搜图的图库 API，给出推荐：

1. 候选：Unsplash、Pexels、Pixabay、Bing Image Search、自有图库（阿里云 / 百度 / 视觉中国等）。
2. 每个维度：中文关键词命中率、key 申请难度、授权 / 版权、免费额度与成本、稳定性、图片质量与可用尺寸。
3. 结合本项目（中文课程 / 读书 / 工作汇报 PPT，动态按内容配图），给出推荐方案与备选。

## Answer

对比结论（中文场景，动态配图）：

| 候选 | 中文命中 | Key/资质 | 版权 | 免费额度/成本 | 高清 |
|---|---|---|---|---|---|
| Pexels | 中（支持 zh-CN） | 免费即申 | 免费商用，需署名 | 200次/时、2万次/月 | 原图 + landscape 1200px |
| Unsplash | 低（偏英文词） | 免费（申请收紧） | 免署名商用 | 1000次/时 | 高清、URL 可动态缩放 |
| Pixabay | 中低 | 免费 | 免费商用，需署名 | 100次/分 | 1280px；1920px 需审核 |
| Bing（Azure） | 高（全网搜图） | 需 Azure 付费档绑卡 | 版权杂、商用有风险 | F0 3次/秒；S1 付费 | 尺寸杂 |
| 阿里云/百度/视觉中国 | 高 | 需企业资质+付费 | 稳（视觉中国最稳） | 付费 | 高清 |

推荐：**Pexels 首选**（免费商用、中文 locale、2万次/月、1200px 横图做整页背景；中文词命中一般时用「中文关键词→英文」翻译兜底）。**Bing Image 备选**（中文命中最高，但 Azure 付费 + 版权风险，仅内部/预览用图，商用交付慎用）。**Unsplash** 作高清质量补充。

来源：Pexels / Unsplash / Pixabay 官方文档、阿里云 / 百度图像搜索文档、Azure 必应搜索定价。

## 决策覆盖（用户拍板 2026-09-29）

最终选型改为 **百度图片在线搜索**（`image.baidu.com/search/acjson` 网页搜索，yiyan-ppt 同款），替代 Pexels 推荐。已向用户提示三点风险并确认接受：① 版权/授权不清（商用有风险）② 非官方接口易失效/反爬 ③ 返回 thumbURL 缩略图分辨率低、做整页背景需再抓原图。
