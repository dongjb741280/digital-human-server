# 确定幻灯片版式清单

Type: grilling
Status: resolved

## Question

本项目 PPT 需要哪几种版式？每种版式承载什么内容，哪些页需要动态搜图配图？

候选版式（需与业务场景对齐）：

- 封面页（cover）
- 目录页（agenda / toc）
- 章节过渡页（section divider）
- 标题 + 要点（当前唯一的内容页型）
- 左图右文 / 左文右图（image + text）
- 全图页（full-bleed image + 标题）
- 图表页（数据图表）
- 对比页（两栏对比）
- 时间线页
- 引用 / 金句页
- 结束页（closing / thanks）

结合业务场景（课程学习汇报、读书分享、工作汇报总结）确定最终清单，并标注哪些版式需要动态搜图配图。

## Answer

**v1 纳入 9 种版式**（按优先级「版式多样性 > 配色字体 > 配图」三档取舍）：

| slug | 名称 | 承载内容 | 配图 |
|---|---|---|---|
| `cover` | 封面页 | 主标题 + 副标题/主题名 + 强调条 | 主题内置背景图 |
| `agenda` | 目录页 | 章节条目列表（编号 + 标题） | 否 |
| `section` | 章节过渡页 | 章节序号 + 章节标题 | 主题内置背景图 |
| `content` | 标题+要点页 | 页标题 + 要点列表（当前唯一内容页，保留为主力） | 否 |
| `image_text` | 左图右文页 | 配图 + 标题 + 要点（图左文右，或反向） | ✅ 动态搜图 |
| `full_image` | 全图页 | 全屏图 + 叠加标题（蒙层保证可读） | ✅ 动态搜图 |
| `quote` | 金句/引用页 | 大字引文 + 出处/说明 | ✅ 动态搜图（可作背景） |
| `comparison` | 对比页 | 两栏对比（左右标题 + 各栏要点） | 否 |
| `closing` | 结束页 | 致谢/总结语 | 否 |

**推到 v2**：`timeline`（时间线）、`chart`（图表）。`chart` 尤其特殊 —— 要求 LLM 输出结构化图表数据（类型 + 系列值），会直接改变 ticket 06 的数据结构，工程量大，v1 不做。

**配图规则**（区分两种「图」）：
- **动态搜图**（百度图片，按内容关键词，用户已拍板接受版权/稳定性/分辨率风险）：仅 `image_text`、`full_image`、`quote` 三个版式 —— 它们的存在意义就是配图，把搜图成本（次数、版权署名、缓存降级）限定在最少版式上。
- **主题内置背景图**（bg_0~3.jpg，静态免费）：`cover`、`section`。
- **不配图**：`agenda`、`content`、`comparison`、`closing`。
