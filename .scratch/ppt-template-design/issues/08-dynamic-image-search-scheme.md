# 确定动态搜图方案

Type: grilling
Status: resolved

Blocked by: 06

## Question

动态搜图的完整方案怎么定？

**已定**（ticket 03）：图库 Pexels 首选、Bing Image 备选、Unsplash 补充。

**待定**：
1. 关键词从哪来：LLM 每页生成（贴合内容） vs 仅 PPT 标题（yiyan 现状，很糙） vs 正文抽取。中文关键词命中一般时是否走「中文→英文」翻译兜底（ticket 03 建议）。
2. 哪些页配图：封面？全图页？图文页？还是所有内容页？背景图 vs 插图怎么区分。
3. 图库已定（用户拍板）：百度图片在线搜索（image.baidu.com 网页搜索）；版权 / 稳定性 / 分辨率风险已确认接受。
4. 缓存 / 降级：搜图结果缓存、失败降级到内置静态背景图、版权署名落哪。

## Answer

**关键词来源**：LLM 每页生成（ticket 06），输出 2~6 字中文主题实义词（如「故宫雪景」）；**不做中文→英文翻译兜底**（Pexels 的建议，百度中文原生直接命中更好）。

**背景图 vs 插图（按版式分两档）**：
- `image_text`（插图）：直接搜关键词，取缩略图/中等尺寸即可（图小、与文字并排）。
- `full_image`/`quote`（背景大图）：搜词加类型修饰（「壁纸」「高清」），且**须抓原图**（thumbURL 分辨率低，整页背景会糊）。

**缓存 / 降级 / 署名**：
- 缓存：按关键词缓存搜图结果（进程内 + 短期落库），同词复用。
- 降级：搜图失败/超时/无结果 → `full_image`/`quote` 回退内置静态背景图 bg_0~3.jpg（按主题取）；`image_text` 降级为纯 `content` 版式（无图纯文）。
- 署名：不主动署名（版权风险已接受）；可选页脚/备注留「图片来自百度图片搜索」作低成本合规姿态。
