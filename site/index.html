常见问题

你可能想问

关于使用、部署与能力的一些常见疑问。

完全免费吗？

完全免费。项目采用 MIT 开源协议，源码全部托管在 GitHub，可自由使用、修改与二次开发。

需要 GPU 吗？

不强求。CPU 也能跑通完整流水线（Wav2Lip 口型、GPT-SoVITS 语音均支持 CPU，macOS Apple Silicon 已验证），只是速度较慢；配备 GPU 可大幅加速。

支持哪些系统？

服务端支持 Linux 与 macOS；前端为 Web 应用，浏览器即可访问，无需安装客户端。

复刻形象 / 声音需要准备什么？

形象复刻需要一段真人出镜的视频，声音复刻需要一小段清晰人声音频。均为 zero-shot 零样本，无需专门训练。

如何开始部署？

按 README 依次启动 Java 服务、Python 编排服务、GPT-SoVITS 与 Wav2Lip 即可，详细步骤见仓库 doc/ 目录下的时序文档。

能接入我自己的业务吗？

可以。系统提供标准 REST 接口与网关鉴权，各 AI 能力均可被集成到已有业务系统中。
