## Agent skills

### Issue tracker

Issues 与 specs 以 markdown 文件存于 `.scratch/<feature>/`。见 `docs/agents/issue-tracker.md`。

### Triage labels

五个标准角色，标签字符串即角色名：`needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix`。见 `docs/agents/triage-labels.md`。

### Domain docs

单 context：根目录 `CONTEXT.md` + `docs/adr/`。见 `docs/agents/domain.md`。
